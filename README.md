## نسخة GitHub Pages الجاهزة

شغّل `npm run prepare:pages` لإنتاج `github-pages/index.html`: ملف واحد يجمع CSS ووحدات JavaScript السبع من المصدر. تبقى ملفات التطوير المترية والرسم والحفظ منفصلة داخل `src/`؛ التجميع خاص بنسخة النشر فقط.

حزمة مستقلة بالمقاسات المحدثة في `D:\الشقه\بيتنا-GitHub-Pages-بالمقاسات.zip`. تحتوي `index.html` و`README.md` و`.nojekyll` فقط، دون الصور المرجعية والفيديوهات ونتائج الاختبارات. ملف HTML يحتوي المقاسات المؤكدة والمستنتجة وتوزيع الفرش؛ التصميمات المحفوظة داخل متصفحك لا تضاف تلقائيًا للحزمة.

يوجد إعداد GitHub Actions في `.github/workflows/pages.yml` لاختبار الموديل وتجميع الموقع ونشره عند تحديث فرع `main`. يتطلب نشر المصدر اختيار GitHub Actions كمصدر Pages. يمكن نشر الحزمة المستقلة مباشرة من جذر فرع بدلًا من ذلك.

عند الانتقال إلى عنوان GitHub Pages، صدّر تصميمك الحالي JSON ثم استورده على العنوان الجديد؛ الحفظ المحلي منفصل بين العنوانين. النشر العام يجعل التقسيمة الافتراضية والمقاسات والفرش الموجودة بالمصدر قابلة للوصول لأي شخص.

## التشغيل على Windows

1. افتح مجلد `D:\الشقه\apartment-planner`.
2. شغّل `start.cmd` بالضغط عليه مرتين. يتطلب وجود Node.js في الجهاز؛ لا تحتاج إلى `npm install`.
3. افتح **http://localhost:4173** في Chrome أو Edge. اترك نافذة التشغيل مفتوحة أثناء الاستخدام. للإغلاق اضغط `Ctrl+C` في نافذة التشغيل.

بديل من PowerShell:

```powershell
cd 'D:\الشقه\apartment-planner'
node server.js
```

يمكن استخدام `npm start` أيضًا. افتح الأداة عبر الخادم المحلي، بدل فتح `index.html` مباشرة، لأن ملفات JavaScript تستخدم وحدات مستقلة. الخادم يستمع على جهازك فقط. بعد توفر Node.js لا تتطلب الأداة أي اتصال بالإنترنت.

## الاستخدام

- **الفرش:** اختر غرفة، وأضف قطعة من المكتبة. اسحبها في 2D؛ اضغط عليها في أي منظر لتعديل موضعها، عرضها، عمقها، ارتفاعها، لونها أو دورانها. يمكن نسخها وحذفها.
- **المقاسات:** عدّل الأبعاد المترابطة وحالة كل قياس: تقدير مبدئي، قراءة أو تقدير، محسوب من المقاسات، أو مقاس فعلي. عرض المكتب مستقل عن الأطفال. حدود الغرف تتغير معًا والفرش يحتفظ بأبعاده؛ قد تظهر تداخلات بعد التعديل، فتحتاج إعادة التوزيع.
- **الأبواب والشبابيك:** اضغط الفتحة في المخطط لتغيير عرضها وموضعها النسبي على الحائط وارتفاعها. للأبواب يمكن عكس جهة الفتح ونقل المفصلة. الفتحات لا تنتقل إلى حيطان أخرى، وتُرفض الفتحات المتداخلة.
- **3D:** اسحب للدوران، واستخدم عجلة الماوس أو +/− للتقريب. `Shift` مع السحب أو زر الماوس الأيمن يزيح الكاميرا. خيار الحيطان المنخفضة يسمح برؤية الفرش. زر البيت يعيد الكاميرا.
- **البدائل:** جرّب البوتاجاز بفرن أو مسطحًا وفرنًا منفصلًا، والدش أو البانيو، والغاز أو الكهرباء للسخان. يحتفظ البديل بالمكان السابق؛ راجع مقاسه والتنبيهات. إن حُذفت القطعة، اختيار البديل يعيدها في مكان مبدئي.
- **التأسيس:** أضف نقاط كهرباء ومياه وصرف، أو ولّد اقتراحات مرتبطة بالأجهزة. حرّك النقاط واضبط ارتفاعها. الاقتراح لا يكرر نقاط الجهاز الموجودة.
- **النسخ:** احفظ التوزيع باسم من «نسخ التصميم»، وافتح نسخة أخرى للتجربة. الحد 25 نسخة. فتح نسخة قابل للتراجع. تصدير JSON يحفظ التصميم المفتوح فقط؛ صدّر كل نسخة تريد نقلها لجهاز آخر.
- **الطباعة:** تطبع نسخة مستقلة من المخطط مع الأبعاد والمساحات وعروض الفتحات وحالة تقديرها. اختر A3 أفقي للحصول على الورقة الكاملة، أو «حفظ كـ PDF». يمكن اختيار A4 مع ملاءمة حجم الورقة من إعدادات المتصفح. نقاط التأسيس تظهر في الطباعة إن كانت طبقتها مفعلة.

## الحفظ

الحفظ تلقائي بعد كل تعديل، داخل `localStorage` في نفس المتصفح ونفس العنوان والمنفذ. «محفوظ تلقائيًا» تعني نجاح الكتابة؛ إن تعذر الحفظ يظهر تنبيه يطلب تصدير JSON. إزالة بيانات الموقع أو استخدام متصفح/منفذ مختلف لن يعرض الحفظ السابق. احتفظ بنسخ JSON للنسخ المهمة. لا توجد حسابات أو خدمة سحابية.

استيراد JSON يفحص إصدار البيانات، هوية هذه الشقة، المقاسات، القطع، الفتحات والنقاط. الملف غير الصحيح لا يستبدل التصميم الحالي. الحد 2 ميجابايت، 400 قطعة فرش و300 نقطة خدمات. يمكن التراجع عن استيراد صحيح. تاريخ التراجع حتى 80 خطوة داخل الجلسة؛ البيانات والتصميمات المحفوظة تستمر بعد إعادة الفتح، لكن تاريخ التراجع لا يستمر.

## الافتراضات الحالية

- 150 م² تقديركم **إجمالي**. المطبخ 3.25×3.25 م، النوم 4.20×3.60 م، الأطفال 4.60×3.60 م، والمكتب بعرض 3.60 م وطول 4.70 م مع خصم ركنته. حمام النوم وطرقة الأوض مستنتجان، وبعض قراءات الريسبشن والطرقة الصغيرة والبلكونة ما زالت للمراجعة.
- الشكل يحافظ على اتصال الغرف، ركنة مدخل المكتب، مدخلي البلكونة، الريسبشن L، وحمام النوم الذي لا يُدخل إلا من أوضة النوم. المنور ينتهي عند حائط المطبخ العلوي والمطبخ يمتد إلى الحد الخارجي تحته.
- الحيطان في النموذج رمزية وسماكاتها غير مقاسة. مجموع الفراغات نحو 116.12 م² بحسب الأبعاد الحالية، ومنها قيم مستنتجة وتقديرية؛ المنور والسلم مستبعدان. ليست هذه مساحة صافية معتمدة للشقة. المساحات المؤكدة محسوبة من الأبعاد المسجلة، وعند مواءمة جميع الغرف على الموقع يجب مراجعة السماكات والحدود. الفرق عن 150 لا يحدد نصيبًا من مساحات مشتركة.
- سمك الحائط 15 سم، السقف 2.8 م، أبعاد الفتحات واتجاهات فتح الأبواب مفترضة وقابلة للتعديل. مجالات الإدخال تحافظ على التقسيمة؛ يُرفض مقاس يترك عرض الحمامات أقل من 1.6 م أو يُدخل ركنة المكتب خلف تقسيم الحمامين.
- سريران منفصلان للأطفال. مكتب لشخصين بشاشتين لكل شخص. سرير كبير ودولاب وتسريحة وتلفزيون للنوم. قعدة يومية بالتلفزيون وقعدة ضيوف بلا سفرة. الأجهزة ومكان غسالة الأطباق والشفاط والحوض موجودة. الميكروويف متاح اختياريًا.
- الغسالة فتحة علوية في الطرقة الصغيرة كتجربة أولية. **تبقى نحو 30 سم فقط في عمق الطرقة، لذا هذا المكان يحتاج مراجعة أو نقل الغسالة**. فراغ رفع الغطاء 60 سم فوق جسمها مفترض ويُعرض عند اختيارها.
- مواقع السخان والتكييف وموديلات الأجهزة والغاز الطبيعي والتشطيبات لم تُحسم. 3D يعرض فرشًا مبسطًا وتشطيبًا محايدًا للتخيل؛ الشقة حاليًا على الطوب.
- تنبيهات التداخل هندسية مبدئية: أجسام الفرش مستطيلة مدوّرة، مع فحص الارتفاعات والحيطان وقطاعات فتح الأبواب وفراغ الغسالة وأبواب الأجهزة. تفاصيل أرجل المكتب، الحواف والأشكال المنحنية لا تدخل في الفحص. لا يحسب البرنامج جميع متطلبات المرور أو تركيب الأجهزة.
- نقاط التأسيس اقتراحات قابلة للتعديل. لا يحسب دوائر كهربائية أو مقاسات مواسير أو مواصفات تنفيذ؛ يلزم قياس ومراجعة بالموقع.

## تنظيم المشروع

| الملف | المسؤولية |
| --- | --- |
| `src/model.js` | البيانات المترية، المقاسات، الحدود المشتركة، الفتحات، المكتبة، البدائل وفحص JSON |
| `src/collision.js` | التداخلات ومساحات الفتح |
| `src/view2d.js` | رسم SVG من الموديل فقط، والمخطط المستقل للطباعة |
| `src/view3d.js` | رسم WebGL بمنظور وعمق وإضاءة، وكاميرا دوران وتقريب |
| `src/store.js` | المعاملات، التراجع والإعادة، الحفظ، النسخ وJSON |
| `src/app.js` | ربط الواجهة والتفاعل بالبيانات والرسم |
| `styles.css` | الواجهة والاستجابة للشاشات والطباعة |
| `server.js` | خادم محلي بسيط لملفات المشروع |

الحيطان لها IDs ثابتة، والفتحات مربوطة بحائطها وموضعها النسبي. الفرش والنقاط لهما IDs وتخزين بإحداثيات مترية. `x` إلى يمين الورقة، `y` إلى أسفلها، `z` ارتفاع فوق الأرض؛ الدوران بالدرجات. كل منظر يقرأ نفس الحالة، ولا توجد نسخة مستقلة للفرش في 3D.

لتطوير الأداة لاحقًا: أضف بيانات القياسات الميدانية والربط بمحاور الحيطان في `model.js`، أو توسّع في خصائص نقاط الخدمات ومواصفات الأجهزة. يمكن استبدال طريقة رسم 3D دون تغيير بيانات التصميم.

## التحقق

```powershell
npm test
```

اختبارات Node لا تحتاج مكتبات إضافية. تشمل اتصال الغرف والفتحات بعد تعديل المقاسات، نهاية المنور، ثبات أبعاد الفرش، التداخلات، البدائل، الحفظ والتراجع والنسخ والتحقق من JSON.

تم إجراء اختبارات Chrome فعلية في `tests/browser.cjs`: السحب، تغيير المقاس والدوران، المقاسات المشتركة، الحفظ وإعادة التحميل، النسخ، تنزيل واستيراد JSON، البدائل، الفتحات، الخدمات، تغيّر الصورة عند دوران وتقريب 3D، الطباعة والشاشات. نتيجة آخر تشغيل في `tests/browser-report.json`. لإعادة اختبار المتصفح فقط، يحتاج الاختبار Playwright وChrome؛ هذه أدوات تطوير وليست متطلبات تشغيل التطبيق.


## نسخة المقاسات الموضحة — ٢

المصدر مقاسات.pdf وتصحيحات المستخدم: الريسبشن كاملًا 5.82 م، الطرقة الصغيرة 2.26 × 1.37 م، عرض أسفل الريسبشن 3.50 م، السقف 3.10 م. مقاسات 9 أبواب و8 شبابيك مضافة إلى النموذج؛ إزاحاتها واتجاه فتحها غير مقاسين. حمام النوم وطرقة الأوض وعرض البلكونة والركنة ومحاذاة الحيطان مؤقتة كما في سجل القياسات وPDF. اختلاف عمق حمام النوم 2.00 في الورقة مقابل 1.90 المحسوب يحتاج قياسًا مباشرًا. مجموع النموذج لا يمثل صافي مساحة معتمدًا. النسخة السابقة محفوظة للمراجعة. تحديث التصميم المحفوظ يتطلب زر تطبيق المقاسات الجديدة ويمكن التراجع عنه.


مراجعة تطابق المقاسات: التصميم الجديد وReset يستخدمان القياسات الأخيرة بما فيها الريسبشن 5.82 م، والطرقة 2.26 × 1.37 م، والسقف 3.10 م. عند فتح حفظ قديم تظهر رسالة واضحة مع زر تحديث يحافظ على فرشك؛ تحديث الملفات وحده لا يستبدل الحفظ. اختبارات tests/measurement-audit.test.js تطابق أطوال الموديل والفتحات مع الورقة وتصحيحاتها.
